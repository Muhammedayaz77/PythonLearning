- Conditional statements

- Lists

- Dictionaries

## Naming Style

This project uses clear names with a type suffix when it helps readability.

```python
studentNameStr = "Ayaz"
studentIdInt = 7
studentMarksFloat = 450.5
studentList = []
studentClassObj = StudentClass()
```

Class names use PascalCase. Unnecessary underscores are avoided.

## Learning Style

- Keep syntax simple.
- Use short and useful comments.
- Keep related operations together.
- Run each file separately to learn the topic.
